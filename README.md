# Сервис — приёмка автомобиля

PWA для осмотра машины при сдаче в сервис: зоны кузова, фото, отметки повреждений, подпись владельца, акт и смета.

- работает офлайн, данные хранятся на устройстве
- установка: открыть install.html на телефоне (Android — Chrome, iOS — Safari → «На экран Домой»)
- index.html — приложение, servis.html — версия одним файлом
