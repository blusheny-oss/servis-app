# Сервис — приёмка автомобиля

PWA для приёмки машины в сервис: неисправности по узлам, смета на запчасти, акт приёма с подписью владельца и акт сдачи работ.

## Что умеет
- осмотр по группам узлов; свои группы и свои описания повреждений;
- в каждой позиции: узел, повреждение, ремонт или замена, цена запчасти, работа мастера, фото, оценка словами;
- отметка «осмотрено, чисто» по группам;
- смета считается сама из позиций (без работы мастера);
- акт приёма и акт сдачи работ (в акте сдачи по каждой строке «запчасть + работа мастера = сумма», в конце три итога);
- подпись владельца на экране;
- работает офлайн, данные и фото хранятся на устройстве.

## Установка
Откройте `install.html` на телефоне и нажмите «Установить приложение» (Android — Chrome, iOS — Safari → «На экран Домой»).

## Файлы
- `index.html` — приложение (единственный файл, всё внутри);
- `manifest.webmanifest`, `sw.js`, иконки — PWA;
- `install.html`, `get.html` — установка и скачивание.
